# קביעת גודל חיבור וגודל גנרטורים — טיקטין תכנון חשמל

אפליקציית עמוד אחד לחישוב גודל חיבור חברת חשמל וגודל גנרטורים
בפרויקט מגורים או מעורב שימושים עד גובה 128 מ'.

**פותח ע״י יובל טיקטין בסיוע AI**

---

## מה יש בקובץ

`index.html` — קובץ אחד ויחיד. כל הקוד, העיצוב והלוגו מוטמעים בתוכו.
אין שרת, אין בסיס נתונים, אין תהליך בנייה. פותחים אותו בדפדפן והוא עובד.

מהאינטרנט נטענות שלוש ספריות בלבד (מ‑cdnjs): ExcelJS לייצוא אקסל,
html2canvas ו‑jsPDF לייצוא PDF. שאר האפליקציה עובדת גם בלי אינטרנט.

## איפה הנתונים נשמרים

בדפדפן של המשתמש בלבד (localStorage), על המחשב או הטלפון שלו.
שום נתון לא נשלח לשום שרת. כל משתמש רואה רק את הטפסים שהוא עצמו שמר.
ניקוי נתוני הגלישה בדפדפן ימחק את הטפסים השמורים.

## איך מעלים

### Lovable

1. לפתוח פרויקט חדש (או קיים) ב‑Lovable
2. להעלות את `index.html` לתיקייה `public/`
3. הכתובת תהיה `https://<שם-הפרויקט>.lovable.app/index.html`

אפשר גם פשוט לבקש מ‑Lovable בצ'אט: "add this file as a static page in public/"
ולצרף את הקובץ. אין צורך להמיר אותו ל‑React — הוא עובד כמו שהוא.

### GitHub Pages

1. ליצור מאגר חדש ב‑GitHub
2. להעלות את `index.html` לשורש המאגר (Add file → Upload files)
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `root`
4. הכתובת תהיה `https://<שם-משתמש>.github.io/<שם-המאגר>/`

שימו לב: מאגר ציבורי עם Pages פירושו שהאפליקציה פתוחה לכל האינטרנט.

### שרת המשרד / דיסק מקומי

להעתיק את `index.html` לכל תיקייה משותפת או שרת פנימי. אפשר גם לפתוח
אותו ישירות בדפדפן בלחיצה כפולה.

### טלפון

לפתוח את הכתובת בדפדפן ולבחור "הוסף למסך הבית" — האפליקציה תיפתח
כמו אפליקציה רגילה. הטפסים נשמרים על הטלפון עצמו.

כל שורה ניתנת לעקיפה ידנית, וניתן להוסיף צרכנים נוספים בכל מיקום.

### גנרטורים

- גנרטור אחד מזין עד 2 בניינים מעל 29 מ', ובנוסף את המרתף המשותף
  וכל כמות בניינים מתחת 29 מ'
- **חישוב בזמן אש:** משאבות ספרינקלרים ×3 (התנעת כוכב‑משולש, אפשרות
  עבודה ברוטור תפוס) + כל מפוחי שחרור העשן והדיחוס + משאבות כיבוי אש +
  המעלית הגדולה בכל בניין. שאר הרכיבים אריתמטי
- **חישוב רגיל:** חיבור אריתמטי של כל עומסי החירום והחיוניים, ללא מקדם
  שימוש וללא מקדם התנעה
- הגודל הקובע הוא הגבוה מבין שני החישובים, ב‑cos φ = 0.8
- העיגול לגודל מסחרי לפי קטלוג שמרלינג סינכרו

### חיבורי חברת חשמל

- ציבורי בניין: סכום כל העומסים ÷ 0.92 = kVA, וזרם = kVA × 1.44
- ציבורי מרתף: כנ״ל, בתוספת 0.9A לכל מקום חניה (מרתף + פיתוח)
- גדלים תקניים: 50, 63, 80, 100, 125, 160, 200, 250, 315, 400, 500,
  630, 800, 910 — מעל 910A נדרש חיבור מתח גבוה

### בקרות

- חניות: הצעה של חניה לכל 45 מ״ר מרתף; סטייה מעל 20% מציגה התרעה
- מפוחי שחרור עשן במרתף: הספק מעל 12 ואט למ״ר מציג התרעה לבדיקה
  מול יועץ המפוחים
